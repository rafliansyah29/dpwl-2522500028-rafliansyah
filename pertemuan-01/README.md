# pertemuan-01
1. kesinambungan PWD-DPW-DPWL
jawab: PWD merupakan Pemograman Web Dasar yang dimana mahasiswa mengenal pertama kali html,css,javascript, dan php. Yang dimana keempat itu umumnya digunakan untuk membuat suatu website. DPW merupakan Desain Pemograman Web yang dimana merupakan lanjutan dari PWD. DPW belajar cara untuk membangun tampilan serta interaktivitas situs. DPWL merupakan Desain Pemograman Web Lanjutan yang dimana merupakan lanjutan dari DPW. DPWL belajar cara membuat aplikasi web yang lebih kompleks menggunakan teknologi modern.
