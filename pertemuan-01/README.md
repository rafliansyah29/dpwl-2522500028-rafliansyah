# pertemuan-01

1. kesinambungan PWD-DPW-DPWL
jawab: PWD merupakan Pemograman Web Dasar yang dimana mahasiswa mengenal pertama kali **html**,**css**,dan *javascript*. Yang dimana ketiga itu umumnya digunakan untuk membuat suatu website. DPW merupakan Desain Pemograman Web yang dimana merupakan lanjutan dari PWD. DPW belajar PHP dan cara untuk membangun tampilan serta interaktivitas situs. DPWL merupakan Desain Pemograman Web Lanjutan yang dimana merupakan lanjutan dari DPW. DPWL belajar cara membuat aplikasi web yang lebih kompleks menggunakan MVC. 

2. perbedaan **PHP** terstruktur dan **MVC**
jawab: PHP merupakan penggabungan antara logika, koneksi *database*, dan tampilan **html** dalam satu file yang sama, sedangkan *MVC* merupakana dipisah menjadi tiga bagian *Model* (database), *View* (tampilan), *controller* (logika)

3. fungsi Model, View, dan Controller
Jawab:fungsi model adalah mengelola data
       fungsi view adalah mengatur tampilan data
       fungsi controller adalah penghubung antara model dan view

4. alur request–response MVC;
Jawab: Browser Controller Model Basis Data Model Controller View Browser

5. pemetaan satu atau beberapa bagian/fitur aplikasi DPW ke Model, Controller, dan View disertai alasan
Jawab: fitur pengajuan surat masuk dan surat keluar 
       Model: Suratmodel alasannya menangani logika bisnis data surat, termasuk pencatatan nomor surat, perihal, tanggal surat dan lain lainnya masuk ke server.
       Controller: Suratcontroller alasannya Mengatur alur disposisi surat
       View: arsip_surat.php alasannya antarmuka pengguna UI yang menampilkan daftar arsip surat berdasarkan kategorinya.

6. Kesimpulan P1
Jawab: dapat disimpulkan bahwa Desain dan Pemrograman Web Lanjutan (DPWL) merupakan lanjutan dari pembelajaran PWD dan DPW. Pada tahap ini, mahasiswa mulai memahami konsep MVC (Model, View, Controller) untuk membuat aplikasi web lebih terstruktur dengan memisahkan pengelolaan data, proses, dan tampilan.

Secara sederhana, Model mengurus data, Controller mengatur proses, dan View menampilkan informasi kepada pengguna. Pemahaman ini menjadi dasar sebelum masuk ke tahap pembuatan struktur MVC secara langsung.
